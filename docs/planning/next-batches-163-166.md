# 第 163–166 批规划：彻底去前缀、跨平台依赖适配与 Apple/Release 优化落地

更新时间：2026-11-22

本批次基于 Clang（`llvm@23.1.3`）+ C++26 统一工具链，继续消除仓库内剩余 `thirdparty.`/`nex::`/工作区内部 `nexus.` 包前缀，解除第三方索引与内核原语的 Linux/x86-64 硬编码限制，并打通 Apple（macOS + iOS）双形态内核交付与 CI/Release 门禁。
