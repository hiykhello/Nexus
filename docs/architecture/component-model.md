# 组件模型与生命周期

状态：Nexus 组件模型设计规范，核心原则见 [核心架构原则](../design-principles/core-architecture.md)。

## 组件与装配

组件按能力划分为入站、出站、L3 端口、路由、DNS 服务及运行时服务。client/server 共享这些组件，角色控制装配与校验；是否允许一个进程启用两个角色仍待确定。

建议以稳定的类型标识连接三项信息：KDL 节点解码器、配置校验器、组件构造器。配置解析先生成类型化模型并完成引用校验，再构造运行对象。

构建时裁剪的能力应可查询；使用未编译的能力时报出明确配置错误。注册入口集中装配，避免依赖跨模块静态初始化顺序。重复类型标识应报错，注册完成后尽量只读访问。

入站、出站、endpoint、承载和平台后端分别装配；同一协议的两个方向可共享 codec，但不要求共用一个运行对象。详见 [协议解耦](protocols.md)、[平台抽象](../platform/abstraction.md) 与 [核心架构原则](../design-principles/core-architecture.md)。这些是源码级组件，不承诺动态插件 ABI。

接口由 ngcpp/proxy facade 表达。流、数据报、L3 包端口各有能力契约，组件无需通过一个巨型接口提供所有操作。

静态能力约束优先使用 concept，项目自有动态多态使用 ngcpp/proxy，禁止以虚函数继承实现。设计时先考虑组合，也允许普通的非虚函数式继承。单签名回调依所有权需求优先采用 `function_ref`、`move_only_function` 或 `copyable_function`，异步保存的回调不得借用寿命不足的对象；具体类型选择见[编码规范](../development/cpp-guidelines.md)。

遵循[C++ 编码规范](../development/cpp-guidelines.md)：组件构造、配置校验和可失败操作优先返回 `std::expected`，正常的查询未命中使用 `std::optional`；必须存在的引用缺失转换为校验错误。异步操作沿用相同错误语义，具体协程结果类型待 Corosio/Capy 集成验证。

## 路由与上下文

建议将共享信息拆为以下类别：

| 类别 | 内容与修改规则草案 |
| --- | --- |
| 流量标识 | 会话 ID、入站、源地址、原始目标，创建后保持稳定 |
| 观察结果 | 嗅探协议、域名、进程信息及可信来源，由对应阶段补充 |
| 路由结果 | 命中规则、出口、目标改写及处理参数，决策后形成快照 |
| 匹配状态 | 规则缓存、阶段进度，仅在本轮匹配期间有效 |

规则由条件与动作组成，动作明确继续、结束、拒绝或推迟。预判阶段只使用已获得的信息；例如 TCP 握手前不能假定已经拥有 TLS ClientHello，UDP 首包也可能不足以完成嗅探。

无法确定的前序规则不能简单跳过后继续命中后序规则，否则预判可能改变完整路由的语义。建议返回“需要更多信息”，进入 L4 阶段后继续处理。

L3 转发仅对具有包端口能力的出口开放；L4 出口接收流或数据报。两条路径共享策略及跟踪数据，但分别定义 MTU、返回路径和关闭语义。

## 生命周期

建议采用以下阶段，名称及接口仍可调整：

1. 校验：检查组件引用、依赖环、平台能力与配置冲突。
2. 初始化：建立服务依赖、运行作用域和内存资源。
3. 准备：打开设备或监听资源，登记对应清理操作。
4. 启用：依赖就绪后启用接入和数据面，报告可用状态。
5. 停止：停止接入，传播取消，等待在途操作结束，再释放资源。

每个子组件拥有取消与清理作用域。创建资源后立即登记清理，启动失败时按依赖逆序回收；关闭应可重复调用。操作系统路由、DNS 和接口变更也属于需要回收的资源。

C++ 析构承担最终资源释放；涉及异步 I/O 的停止过程需先显式等待完成。不能让析构函数隐式承担不可控的异步等待，也不能在协程仍引用缓冲区时销毁资源。

可失败的显式关闭返回错误结果，析构不抛出。回滚过程继续执行其余清理并收集诊断，避免一次关闭失败导致后续资源泄漏。

## 可观察性

统一记录会话 ID、入站、出口、命中规则、L3/L4 路径、双向字节数及结束原因。拒绝、超时、取消、队列拥塞和协议错误分别统计，便于定位性能瓶颈和行为差异。

协议握手返回有标签的转发计划，显式携带初始数据、成功响应和 flush 要求，由公共转发器处理双向传输。包、字节流和会话数据报保持独立语义，优化后仍保留计数与取消。详见 [性能设计](performance.md) 与 [性能与数据面原则](../design-principles/performance-and-datapath.md)。
