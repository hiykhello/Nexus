# 0006：KDL 与 BEVE 规则集及双向转换

日期：2026-10-27。状态：格式方向与互转需求已确定，尚未实现。来源：用户追加要求。

## 决策

- 提供 KDL 2.0 文本规则集与 BEVE 二进制规则集。
- 两者都基于同一规则语义模型，支持 KDL → BEVE 与 BEVE → KDL。
- 使用指定 Glaze 分支的格式能力，Nexus 定义自身 schema、语义校验与版本边界。
- BEVE 必须保留足以恢复规则文本语义的数据，编译索引不作为不可逆的唯一表示。

## 边界

往返保证规则语义、顺序与逻辑结构；不保证注释、原排版或未经定义的字节级完全一致。未知必要语义必须失败，不能静默丢弃。

精确 schema、外层封装、后缀、压缩、版本迁移和 CLI 仍待验证；CBOR 等保留为对比与未来扩展，不作为当前第二套二进制承诺。

格式依据见[二进制设计](../architecture/rule-set-format.md)，互转与验收见[规则集转换](../configuration/rule-sets.md)。
