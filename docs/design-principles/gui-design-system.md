# GUI 设计系统与交互工程原则

本文沉淀 Nexus 跨平台图形客户端（Desktop Slint、Android Compose、Apple SwiftUI 与 Web 控制台）的产品边界、信息架构、哑光视觉规范、渲染与内存红线及四端统一基线。

## 1. 产品边界：裸核 CLI vs GUI 客户端

Nexus 同时服务高阶运维场景与日常图形代理场景，二者在抽象层级与用户心智模型上严格分界：

| 维度 | 裸核 CLI（`nexus`） | GUI 客户端（桌面 / 移动 / Web） |
| --- | --- | --- |
| **面向概念** | 声明式配置文件、路径、控制端点、信号与自动化脚本 | 节点、订阅、策略组、路由、DNS、出站模式、活动连接与实时日志 |
| **文件与路径管理** | 用户显式指定配置、状态目录与凭据路径 | 应用私有目录静默自管理，UI 零路径暴露 |
| **变更方式** | 编辑配置文件或调用 CLI / API 重载 | 工作区统一编译下发 + 实时控制面热切 |

GUI 客户端必须遵守以下三条硬性产品边界：

- **应用私有目录静默自管理**：客户端自动在各自平台私有目录（Linux `$XDG_CONFIG_HOME` / `$XDG_DATA_HOME`、Windows `%AppData%` / `%LocalAppData%`、macOS/iOS App Group 容器、Android `noBackupFilesDir`）内管理内核二进制、本地工作区数据库、运行时编译产物与受保护凭据文件（POSIX `0600` / Android Keystore / Apple Keychain）。**UI 严禁展示内部文件路径、数据库文件名、Socket 路径、缓存路径，也严禁要求用户手动填写目录。**
- **全面去底层术语化**：界面可见文案、标签、按钮、占位符、空状态与错误提示中**严禁裸露 `KDL`、`SQLite`、`WAL`、`/v1/*`、`BEVE` 等底层实现术语**；所有错误反馈必须转译为用户可理解的原因与一键修复动作。面向极少数需手写完整配置的高阶用户，仅在配置页次级折叠入口提供低调的**「高级自定义配置」**逃生舱。
- **单一真源与单一控制通道**：
  - **配置单一真源**：所有客户端配置编辑（节点、订阅、路由、DNS、宿主网络开关）统一写入本地工作区，并经由共享 Core 编译器（参见[四支柱配置边界](../architecture/config-boundary.md)）生成全量校验后的运行配置；**严禁旁路文本拼接或正则注释块修补配置文件**。
  - **运行态单一控制面**：状态轮询、实时速率与连接流、出站模式切换（规则 / 全局 / 直连）、策略组切点、批量探活、缓存清理与日志流统一走本机回环 HTTP + SSE 控制面，并支持平滑演进至多路复用 RFC 6455 WebSocket（`GET /v1/ws`：原生客户端走 `Authorization: Bearer` 请求头鉴权，浏览器客户端走首帧鉴权，完整协议与内置 Web 控制台托管契约参见[原生控制面与 IPC](../architecture/control-api.md)）；**严禁将 Bearer 令牌经 URL query 传参或落入日志**；流式连接断线重连后必须经快照接口重建一致视图。

## 2. 桌面端零滚动 4 行 Bento 控制台信息架构

桌面控制台以**信息密度均衡、零视觉噪音、标准视口一屏尽览**为第一原则：

### 2.1 可折叠超窄图标侧栏

- **默认收起宽度 `54px`**（展开后 `196–208px`）：顶部放置品牌图标，中部仅保留 **6 个一级核心入口**——`概览`、`代理`、`连接`、`配置与订阅`、`日志`、`设置`；底部固定**「展开 / 收起」**与一键**「亮 / 暗切换」**两个实用控件。
- **移除导航视觉噪音**：不显示分组副标题（如「核心 / 网络 / 系统」）与常驻键盘快捷键角标；全局键盘快捷键仍完整保留，并在悬停 Tooltip 中提示功能名称与对应快捷键。

### 2.2 主视口零滚动 4 行网格

标准桌面视口（`1280×760`）在概览页实现**零垂直滚动一屏完整呈现**；收窄至紧凑断点（`780×560`）时平滑切换为垂直堆叠布局，确保零横向溢出、零文字截断。包含实时链路拓扑仪与双轨吞吐波形在内的旗舰扩展行高精确预算见[GUI 旗舰设计与逐界面规范](gui-flagship-spec.md)第 2.2 节。

```text
+----------------------------------+-------------------+-------------------+
| Row 1 (2fr : 1fr : 1fr)          |                   |                   |
| 状态主卡（节点/协议/延迟/启停钮） | 实时上传（峰/累计）| 实时下载（峰/累计）|
+----------------------------------+-------------------+-------------------+
| Row 2 (2fr : 1fr : 1fr)          |                   |                   |
| 活动连接预览（计数/活跃流/详情>） | 软件性能（PID/CPU/内存）| 内核性能（PID/CPU/内存/快清）|
+------------------+---------------+---+---------------+-------------------+
| Row 3 (1fr x 4)  |                   |               |                   |
| 服务连通检测(4项) | 分流规则(直达诊断) | 出站模式(三段) | 策略组快切(2×2)    |
+------------------+-------------------+---------------+-------------------+
| Row 4 (1fr x 4)                                                          |
| [ 端口代理 ]     | [ 局域网代理 ]    | [ 系统代理 ]   | [ TUN 模式 ]      |
+------------------+-------------------+---------------+-------------------+
| Footer (32px): 单行状态提示               [网络检测] [测速全部] [启动/停止] |
+--------------------------------------------------------------------------+
```

各区域职责与不变量：

- **Row 1（状态与速率，`2fr : 1fr : 1fr`）**：
  - **状态主卡（`2fr`）**：展示当前出口节点、协议标签、实测延迟、运行时长，右侧放置一键启停主圆钮，完整承载五态反馈（待机 / 启动中 / 已连接 / 降级 / 异常）及行内可恢复提示。
  - **实时上传卡（`1fr`）与实时下载卡（`1fr`）**：主指标为实时速率，右上角展示峰值，副标题展示累计流量，底部配以简洁平直的迷你波形图。
- **Row 2（活动连接与双进程独立性能，`2fr : 1fr : 1fr`）**：
  - **活动连接预览卡（`2fr`）**：展示活跃连接计数胶囊、前 3–4 条活跃流紧凑摘要（目标主机、命中规则/出口、实时字节）或干净空状态，右上角提供 `详情 >` 入口直达连接页。
  - **软件性能卡（`1fr`）**：独立展示客户端自身 `PID`、CPU 占用率与私有内存。
  - **内核性能卡（`1fr`）**：独立展示 Core 运行状态 / `PID`（未启动时明确标示）、内核 CPU 占用率与私有内存，并内联 `FakeIP` / `DNS` 缓存快清动作。
  - **双进程资源严格分卡原则**：客户端进程与内核进程资源消耗必须分卡独立呈现，**严禁相加合并为一个误导性的“总内存”大字标题**。
- **Row 3（四等分实用控制台，`1fr × 4`）**：
  - **服务连通检测**：4 项常用服务真实穿代理探活延迟与超时状态，附快速重测按钮；
  - **分流规则命中**：规则条数与命中概览，右上入口直达 **5 标签规则与 DNS 诊断弹窗**（规则列表 / 规则匹配测试 / 实时 DNS 查询 / 规则集管理 / 缓存维护）；
  - **出站模式**：`规则` / `全局` / `直连` 三段式切换器，经控制面即时生效；
  - **策略组快切**：紧凑 `2×2` 常用策略组切换胶囊，右上入口跳转代理页。
- **Row 4（底排对齐快捷开关条，`1fr × 4`）**：4 枚等宽贴底瓦片——`端口代理`（附本地混合端口摘要）、`局域网代理`、`系统代理`、`TUN 模式`，状态清晰、操作一致。
- **极简底部状态与动作栏（`32px`）**：左侧单行状态提示与轻量反馈；右侧收敛高频全局动作（`网络检测`、`测速全部`、`启动 / 停止代理`）。

### 2.3 明确禁止的反模式

- **禁止悬浮右下角 FAB**：全局动作统一收口至底部状态栏、主状态卡与子页标题栏，绝不以悬浮圆钮遮挡内容或底排开关。
- **禁止概览页拖拽重排与自定义卡片开关模式**：坚持唯一经过精调的固定 4 行网格，消除拖拽编辑铬框与布局配置状态膨胀。
- **禁止设置页堆砌视觉特效调试滑块**：移除材质强度、窗口不透明度、表面磨砂与环境光晕滑块；设置页收敛为**外观（深/浅/跟随系统、强调色、语言、减弱动态效果）**、**行为（托盘与开机自启）**、**网络与 TUN**、**快捷键**与**关于**。

## 3. 克制哑光视觉语言与 GPU / 内存硬性红线

### 3.1 哑光扁平精密层次

摒弃高开销重玻璃拟态，采用**哑光扁平精密**视觉语言，依靠排版层级、克制留白、1px 精细描边与高对比语义色建立空间秩序：

| 语义角色 | 深色哑光（Dark） | 浅色纸感哑光（Light） | 用途与约束 |
| --- | --- | --- | --- |
| **窗口画布** | `#111317` | `#F5F6F8` | 全局主背景，低眩光底板 |
| **一级卡片面** | `#191C22` | `#FFFFFF` | Bento 卡片与主内容容器 |
| **次级控件 / 悬停面** | `#20242C` | `#ECEFF3` | 输入框、分段底槽、悬停态 |
| **1px 精细描边** | `#262A33` | `#E0E4EC` | 替代重阴影定义卡片与控件边界 |
| **主文本 / 次文本** | `#ECEFF4` / `#9AA3B2` | `#151820` / `#555E6E` | 严格满足 WCAG AA 对比度 |
| **语义强调色** | 强调蓝 `#3B82F6` · 健康绿 `#22C55E` · 警告琥珀 `#F59E0B` · 异常红 `#EF4444` | 强调蓝 `#1D4ED8` · 健康绿 `#15803D` · 警告琥珀 `#B45309` · 异常红 `#DC2626` | 仅用于主激活态、延迟分档与告警，避免大面积高饱和铺底 |

- **数字与排版基线**：所有实时数值统一启用等宽数字（`tabular-nums`）并配定宽数值槽防抖动（详见第 4.2 节）。
- **四档仪器主题与双信号色扩展**：在基础深/浅哑光体系上，四端统一的四档预设（`跟随系统`、`曜石仪表`、`暖纸日光`、`精密琥珀`）、活态链路 Signal Emerald 分工与全量 WCAG 2.1 AA 色阶基准见[GUI 旗舰设计与逐界面规范](gui-flagship-spec.md)第 1 节。
- **原生背景能力降级为静默可选**：桌面系统级窗口模糊仅在不损害正文对比度与显存预算的前提下可选启用，绝不成为层次成立的前提。

### 3.2 渲染性能与 GPU / 进程内存红线

- **严禁 `animate drop-shadow-blur`**：绝不允许对阴影模糊半径做过渡动画。在 Skia 等 GPU 加速后端中，逐帧变化的模糊半径会迫使管线为每一帧分配并缓存新的离屏高斯模糊纹理，导致普通标签切换与悬停交互即可触发百 MiB 级 PSS / `RssAnon` 暴涨。交互反馈一律改为动画化 `border-color`、`background` 或不改变模糊半径的纯色透明度。
- **严禁高频元素使用 `drop-shadow-blur`**：卡片、列表项、表格行、开关、胶囊按钮与输入框一律禁用 `drop-shadow-blur`，统一使用 1px 描边与哑光表面阶梯表达层次。
- **严禁装饰性离屏绘制与空闲帧空转**：禁止卡片顶边静态高光反射条（`GlassSpeculum`）、角落大面积环境光斑（`ambient-glow`）以及空闲期 60fps 常驻 `animation-tick()`；窗口隐藏至托盘或后台时暂停动态采样与动画，空闲 CPU 趋近 `0%`。
- **硬件渲染与全优化构建纪律**：坚持硬件加速渲染（绝不为掩盖渲染泄漏而回退 CPU 软渲染）；Slint C++ 构建坚持**完整 Release 优化级别（GCC/Clang `-O3`、MSVC `/O2`）**，不得为缩短编译时间而下调桌面端生成代码的优化级别，而是通过配置 `COMPILATION_UNITS` 并行拆 TU 与精简 UI 组件结构（杜绝冗余卡片与特效包装）同步兼顾运行效率、二进制体积与增量编译速度。

### 3.3 跨平台私有内存统计与空闲回收契约

- **真实私有工作集采集口径**（与操作系统任务管理器对齐，软件与内核进程各自独立采样）：
  - **Linux**：读取 `/proc/<pid>/smaps_rollup` 的 `Private_Dirty + SwapPss`（不支持时回退 `/proc/<pid>/statm` 私有页估算）；
  - **Windows**：读取 `PROCESS_MEMORY_COUNTERS_EX::PrivateUsage`；
  - **macOS / iOS**：读取 `proc_pid_rusage(..., RUSAGE_INFO_V4)` 的 `ri_phys_footprint`。
- **空闲与托盘主动回收**：窗口收进系统托盘、移动客户端切入后台或用户手动触发内存整理时，执行本地数据库 `PRAGMA shrink_memory; PRAGMA wal_checkpoint(PASSIVE);`，并按平台向操作系统归还空闲堆页（Linux glibc `malloc_trim(0)`、Windows `_heapmin()` / `SetProcessWorkingSetSize`、macOS `malloc_zone_pressure_relief`），杜绝交互峰值永久锁定驻留内存。

## 4. 精密交互工艺、动态克制与状态纪律

优秀的工具型客户端依靠数百个“不易察觉却处处准确”的细节建立工程质感，四端共享以下工艺硬约束：

### 4.1 按使用频次分级的动态克制（Frequency-Based Motion Restraint）

动态效果采取**举证倒置**：每一处动画都必须能明确回答目的（反馈、状态指示、空间连贯或避免突兀跳变），按用户日均触发频次分级克制：

| 交互频次与类别 | 动态预算 | 典型场景与硬性禁忌 |
| --- | --- | --- |
| **极高频 / 键盘触发**（日均 `100+` 次） | **0ms 零动画** | 快捷键切页、命令面板开关、焦点跳转、侧栏导航切换、表格/波形定时刷新——任何过渡时长都会被感知为延迟 |
| **日常高频**（日均数十次） | **仅纯色/描边过渡，`<= 150ms` `ease-out`** | 列表行悬停、卡片聚焦、开关切换、分段控件、策略组胶囊——**严禁悬停放大/上浮、弹性弹簧与模糊半径动画** |
| **偶发浮层**（弹窗 / 抽屉 / Toast） | **`150–250ms` 强 `ease-out`（退出快于进入），`scale(0.95) + opacity` 起手** | 严禁从 `scale(0)` 凭空出现；严禁起步迟缓的 `ease-in`；锚定气泡从触发源缩放（居中模态窗保持中心缩放） |
| **按压与悬停细节** | **按下即响应（`pointer-down` / `:active`），`100–160ms`** | 按钮与主启停键按下即给细微反馈，绝不等到松手才亮；工具栏 Tooltip 首次轻延迟，连续滑过相邻项时跳过延迟与动画 |

- **合成层优先与可中断性**：仅对合成属性（`transform`、`opacity`）与必要背景/描边色做显式过渡，**严禁 `transition: all`**、严禁逐帧动画布局属性（`width`/`height`/`padding`/`margin`）或父容器继承变量；所有进行中的过渡必须支持随时中断并从当前视觉值平滑反向，绝不在过渡期间锁死输入。
- **拒绝装饰性噪声**：严禁功能性图表或统计数字在每次页面挂载/刷新时归零重绘；严禁对 `< 300ms` 完成的瞬时操作闪现加载转圈或骨架屏；严禁在常驻元素上运行无限循环呼吸/流光动效；删除冗余动画时须同步清理隐藏初始态（如 `opacity: 0`）与依赖动画结束回调的聚焦/卸载逻辑。

### 4.2 同心几何、光学对齐与数字防抖动

- **同心圆角定律**：嵌套容器严格遵循 `outer_radius = inner_radius + padding`（如 `16px` 卡片圆角配合 `8px` 内边距对应 `8px` 内嵌控件圆角；`12px` 卡片配合 `6px` 内边距对应 `6px` 胶囊），保证内外圆弧平行协调、无视觉挤压。
- **光学对齐与排版尺度**：图标与文字按视觉重心而非机械外框居中对齐；字距与行高随字号反向调节（大标题微收紧字距与行高，小字与正文保持清晰舒展）；优先采用平台系统字体族以获得原生光学字号与中英混排锐度。
- **`tabular-nums` + 定宽数值槽**：实时速率、延迟（`ms`）、内存（`MiB`）、CPU 百分比与连接计数不仅启用等宽数字，还必须配合右对齐或定宽数值槽，确保高频刷新时同行标签、单位与按钮**零水平抖动**；弹性容器内的长域名/路径子项须设置 `min-width: 0` + 省略截断与完整 Tooltip。
- **克制 1px 细线与选区边界**：容器边界统一使用单层 1px 细腻描边，**避免多层边框堆叠或发灰混浊阴影**；按钮/标签页/胶囊等纯控件禁用文本选中（`user-select: none`），但节点地址、域名、报错与日志等数据内容始终保持可选可复制。

### 4.3 零抖动状态流、乐观反馈与诚实错误纪律

- **刷新保活滚动与选区**：实时连接表、日志流与节点列表在增量更新或筛选重算时，严格保留用户当前的滚动偏移、选中条目与详情抽屉状态，绝不将视口弹回顶部或重置输入焦点；高条目列表采用虚拟化或有界窗口防止主线程掉帧。
- **乐观即时反馈与精确回滚**：切换出口节点、出站模式或代理开关时在**首帧立即反映目标态**，后台异步提交控制面或工作区；若提交失败，精确回滚至实际生效态并在操作原位给出**具体失败原因与一键重试/修复入口**（禁止模糊的孤立报错弹窗）。
- **诚实空状态与克制确认**：每个空视图（无节点、无活动连接、筛选无命中）明确说明原因并提供**唯一清晰主动作**（如「导入订阅」「重置筛选」）；仅对不可逆破坏性操作（清空全部缓存、断开全部连接、删除订阅）采用轻量二次确认或可撤销窗口，避免高频滥用确认框。
- **跨端输入与原生层打磨**：
  - **触控与指针按能力门控**：所有悬停样式限定于精确悬停指针（Web `@media (hover: hover) and (pointer: fine)`），彻底消除触屏点击后悬停粘滞；按钮与链接启用 `touch-action: manipulation`（消除点击延迟）并去除浏览器默认灰闪，移动端有意义的触觉反馈与状态变化同帧触发。
  - **视口、安全区与无障碍缩放**：Web / 移动界面采用动态视口（`100dvh`）、安全区适配（`viewport-fit=cover` + `env(safe-area-inset-*)`）与局部滚动防穿透（`overscroll-behavior: contain`）；输入框字号不小于 `16px` 防止移动浏览器自动放大页面（**严禁使用 `user-scalable=no` 或 `maximum-scale=1` 禁用缩放**）；暗/亮主题同步系统 `color-scheme` 与状态栏 `theme-color`。

### 四端共同可访问性与诊断基线

- **触控与点击热区**：移动端所有可交互目标不小于 `48×48dp`；桌面指针端高频紧凑操作区保证清晰悬停态与键盘焦点环，杜绝“可点击卡片内嵌套按钮”导致键盘触发误切节点。
- **字体缩放与对比度**：全面支持系统 `200%` 字体缩放而不重叠截断；深浅双主题均满足 WCAG 2.1 AA（正文 `>= 4.5:1`，大字/图标/控件描边 `>= 3:1`），状态编码永不单一依赖颜色（同步辅以文字或图标语义）。
- **动态效果尊重**：严格读取并响应各平台 `Reduced Motion` / 系统动画缩放开关，关闭非必要过渡与波形动效。
- **统一 10 域日志与双语国际化**：四端日志筛选器严格对齐 Core 全部 **10 个日志域**（`core`、`net`、`tls`、`quic`、`dns`、`route`、`tun`、`proxy`、`control`、`state`），提供完整的简体中文 / English 双语切换，且所有面向用户的文案均严格遵守第 1 节“去底层术语、零内部路径”纪律。
- **旗舰交互与逐界面深化**：实时链路拓扑仪、全局 `Ctrl+K` / `⌘K` 命令与内联域名诊断面板、双轨事件刻度波形、策略组延迟光谱分布条及逐界面对齐矩阵与验收门禁详见[GUI 旗舰设计与逐界面规范](gui-flagship-spec.md)。
